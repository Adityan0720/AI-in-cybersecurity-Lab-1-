# Data

## KDDTrain+.txt

This project uses the NSL-KDD `KDDTrain+.txt` training file for cybersecurity EDA.

Source: Canadian Institute for Cybersecurity, University of New Brunswick

Dataset page: https://www.unb.ca/cic/datasets/nsl.html

The file is headerless and contains 41 NSL-KDD features followed by `label` and `difficulty_level`.
